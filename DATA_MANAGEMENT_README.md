# Data Management

The Phase 1 Data Management page is available at `/data-management`.

It provides:
- System readiness score
- Import order and dependencies
- Links to existing location, planogram, machine-log, restock, staffing, product, and GIS workflows
- Live record counts
- Data-quality exceptions
- Import-history audit table

Run `supabase/data-management-migration.sql` before using the detailed readiness metrics.
